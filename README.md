# Kiln feedback

Report a problem with [Kiln](https://kilnviewer.com) or suggest something it should do.

- **Something is broken:** [open a bug report](https://github.com/kiln-viewer/feedback/issues/new?template=bug.yml)
- **Something is missing:** [suggest a feature](https://github.com/kiln-viewer/feedback/issues/new?template=feature.yml)

Problems with your Second Life account, billing, land or the grid itself are handled by Linden Lab: [support.secondlife.com](https://support.secondlife.com).
